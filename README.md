# NEXORA Launcher Releases

This repository contains public Windows release downloads for the NEXORA Launcher. The launcher source code is maintained separately in a private repository.

## Downloads

Open [Releases](https://github.com/yannik281200/NEXORA-Launcher-Releases/releases/latest) to download the latest setup installer or portable executable.

- **Setup installer**: recommended; installed copies can check for and install launcher updates.
- **Portable executable**: runs without installation; download a newer portable build manually when one is released.

The launcher checks for updates in the background at startup. If one is available, it appears in the launcher's **Updates** section.
